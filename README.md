# TaskFlow

Aplicativo Flutter de controle de tarefas utilizando Provider e ChangeNotifier.

## Requisitos
- Flutter
- Dart
- Android Studio ou VS Code

## Como executar

1. Extraia o ZIP.
2. Abra a pasta `taskflow` no Android Studio ou VS Code.
3. Execute no terminal:
   `flutter pub get`
4. Escolha um dispositivo/emulador.
5. Execute:
   `flutter run`

## Conceitos utilizados
- Flutter
- Provider
- ChangeNotifier
- notifyListeners()
- Estado compartilhado entre páginas
- Navigator
- Formulários e listas
